About Us

We are Isha Patel, Brandon Ekow Anderson, and Francisco Arenas. And under the supervision of Jeff Ondich, our project "Your Browser is Spying on You! Identifying Maliciousness in Browser Extensions" focuses on detecting potentially malicious behaviors in Chrome browser extensions.

We built a web application that allows users to search for a browser extension and receive a detailed report describing its potential maliciousness. The system scans the extension's files, extracts structural and behavioral features, and uses machine learning models to evaluate whether the extension may pose a security risk.

The resulting report provides users with insight into the extension's permissions, code characteristics, and other indicators that may suggest suspicious activity.
